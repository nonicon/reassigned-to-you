A make.fun entry for **The Vacuum's Alibi: One Line, 200 Characters**
([bounty page](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7)).

`main.py` writes one line to `/output/entry.txt`: the excuse a robot
vacuum gives for missing a spot. The line is fixed and deterministic,
so every run produces the exact same entry.

Run it:

```sh
python3 main.py
```
